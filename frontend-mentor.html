Présentation

Frontend Mentor est une plateforme proposant des défis d'intégration basés sur des maquettes professionnelles fournies en PNG et Figma. L'objectif est de reproduire le design aussi fidèlement que possible, en HTML, CSS et JavaScript purs — sans framework imposé.

Ces exercices permettent de travailler la précision du CSS, la gestion du responsive, la logique JavaScript et le sens du détail visuel — des compétences directement valorisables en entreprise et dans le cadre du BTS SIO.

Calculator App — Détail

Thème 1 — Clair
Thème 2 — Sombre
Thème 3 — Violet
—Gestion des thèmes dynamiques
  • 3 thèmes visuels switchables via un toggle slider
  • Utilisation de variables CSS pour la gestion cohérente des couleurs
  • Transition fluide entre les thèmes sans rechargement de page
—Logique de calculatrice en JavaScript
  • Opérations : addition, soustraction, multiplication, division
  • Gestion de l'affichage (chiffres, opérateurs, résultat)
  • Touche DEL pour effacer le dernier caractère, RESET pour tout effacer
  • Gestion des cas limites (division par zéro, chiffres décimaux)
—Interface responsive
  • Adaptée aux écrans desktop et mobile
  • Boutons avec ombres et états actifs (:hover, :active)
  • Grid CSS pour la disposition du clavier
