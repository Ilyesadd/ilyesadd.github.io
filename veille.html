Lexique Technique

RT
RAY TRACING

Technique de rendu qui simule le trajet physique des rayons lumineux dans une scène 3D pour produire des réflexions, réfractions et ombres photoréalistes.

DXRRTXVulkan RT
PT
PATH TRACING

Extension du ray tracing qui simule l'illumination globale complète. Chaque rayon rebondit plusieurs fois, produisant des rendus quasi-photographiques mais très coûteux.

GIMonte Carlo
AI
DLSS / FSR

DLSS 4 (NVIDIA) utilise un réseau de neurones pour reconstruire une image haute résolution. FSR 4 (AMD) est l'alternative open source basée sur l'apprentissage automatique.

UpscalingIAFPS++
VK
API VULKAN

API graphique bas niveau multi-plateforme (Khronos Group). Donne un contrôle fin sur le GPU, réduit le CPU overhead. Supporte le ray tracing via l'extension VK_KHR_ray_tracing.

Cross-platformLow-level
SH
SHADERS

Programmes exécutés sur le GPU définissant couleur, lumière et effets visuels. Types : vertex, fragment, compute, ray generation, closest hit, miss shaders.

GLSLHLSLSPIR-V
UE
LUMEN / NANITE

Lumen est le système GI dynamique d'Unreal Engine 5. Nanite est sa géométrie virtualisée permettant des milliards de polygones en temps réel.
